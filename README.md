# Phonepe-Analysis-Dashboard
#PhonePe Transaction Analysis 📱📊

##Project Overview

This project analyzes PhonePe transaction data to understand digital payment trends and transaction patterns. Excel is used for data analysis, while Power BI is used to create an interactive dashboard for visualizing insights.

##Tools Used

Microsoft Excel

Microsoft Power BI

Data Visualization

Data Analysis

##Project Files

Excel File: Contains the transaction data and analysis.

Power BI File (.pbix): Contains the interactive dashboard.

##Key Objectives

Analyze transaction trends and patterns.

Explore transaction performance across available categories and time periods.

Present key findings through charts and visualizations.

Build an interactive dashboard to support data-driven decision-making.

##Skills Demonstrated

Data cleaning and preparation

Exploratory data analysis

Dashboard development

Data visualization

Business reporting

##Business Value

This analysis helps users understand digital payment trends and explore transaction performance through visual reports.
